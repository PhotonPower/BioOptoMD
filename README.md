# BioOptoMD
BioOptoMD ist ein modulares C++/CUDA-Molekulardynamik-Framework mit Python-API, das die Dynamik von Biorezeptoren an nanostrukturierten Sensoroberflächen simuliert und in-situ optische Kopplungsparameter (Dipole, FRET, Brechungsindexprofile) als direkten Input für elektromagnetische Optik-Solver berechnet.
